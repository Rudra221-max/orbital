ORBITAL is a free, first-person browser game that trains students like junior astronauts. Players float outside a space station wearing a helmet visor with a live HUD for oxygen, jetpack fuel and mission time. They complete three missions: repairing cracks in a station, catching floating debris, and getting through an airlock. Each mission ends with a quiz based on real NASA missions and science. It makes space science feel like a real spacewalk, with no download or special hardware.
